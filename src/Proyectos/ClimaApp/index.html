Sobre el proyecto

ClimaApp es una aplicación web enfocada en la consulta de información meteorológica. El proyecto fue desarrollado con el objetivo de crear una interfaz sencilla que permita al usuario conocer las condiciones climáticas de una ubicación determinada.

La aplicación presenta la información de manera clara y organizada, facilitando la consulta de datos relacionados con el estado actual del clima y el pronóstico del tiempo.
